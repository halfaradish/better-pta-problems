# 商店上架手册（Chrome / Edge / Firefox）

本文件是维护者提交商店时照着做的清单；扩展的构建与校验已工程化进 `npm run` 与 CI。

## 0. 三个商店的差异速查

| | Chrome Web Store | Edge Add-ons | Firefox AMO |
|---|---|---|---|
| 开发者账号 | 一次性 $5 注册费 | 免费（Microsoft Partner Center） | 免费（AMO 账号） |
| 上传包 | `dist/store/better-pta-problems-chrome-v<版本>.zip` | `...-edge-...zip` | `...-firefox-...zip` |
| 包结构 | **zip 根目录直接是 manifest.json** | 同 Chrome | 同 Chrome |
| 后台模型 | `background.service_worker` | 同 Chrome | `background.scripts`（事件页） |
| 权限模型 | 安装时授予 | 同 Chrome | host 权限用户可撤销，需运行时兜底 |
| 数据声明 | 隐私问卷 + 隐私政策 URL | 隐私信息 + 隐私政策 URL | manifest 的 `data_collection_permissions` + 运行时同意 |
| 更新 | 商店审核后自动更新 | 商店审核后自动更新 | AMO 审核后自动更新 |
| 审核时长 | 约 1–7 个工作日，新开发者可能更久 | 约 1–7 个工作日 | 数天到数周（人工） |

## 1. 本地构建与自检

```bash
npm ci
npm run build -- --target all       # extension/ + dist/edge/ + dist/firefox/
npm run validate:manifests          # 三份 manifest 的公共字段与专属键
npm run lint:firefox                # web-ext lint，0 error 才能提交
npm run package:store -- --target all
```

产物：

```
dist/store/better-pta-problems-chrome-v<版本>.zip
dist/store/better-pta-problems-edge-v<版本>.zip
dist/store/better-pta-problems-firefox-v<版本>.zip
```

`package:store` 会回读 zip，断言 `manifest.json` 在根目录、没有多套父目录、三份版本一致。

## 2. 提交前必须准备的材料

- **隐私政策 URL**：可直接使用仓库里的 [隐私政策](./隐私政策.md)（建议同时启用 GitHub Pages 或把同一份内容发布到稳定 URL）。三个商店填同一个 URL。
- **商店文案**：可直接用下面的版本（按商店上限微调）。

  **短描述（≤132 字符）**

  > 非官方 PTA 题目集增强：按课程分组筛选、显示进度与截止倒计时、本地/邮件提醒；可选 AI 辅助作答（默认关闭，需自备 API Key）。

  **长描述**

  > 更好的题目集（PTA 增强）是非官方浏览器扩展，帮助你在 PTA（pintia.cn）上更清楚地管理题目集：
  > - 按课程分组与筛选，跨页聚合并保持吸顶筛选条；
  > - 卡片显示课程徽章、答题进度与截止倒计时；
  > - 截止前 3 天 / 1 天的浏览器本地通知；可选邮件提醒（需自建后端）；
  > - 可选的 AI 辅助作答（默认关闭）：支持判断 / 单选 / 填空 / 编程 / 函数题，使用你自己的 DeepSeek、OpenCode Go 或任意 OpenAI 兼容端点；API Key 只存放在浏览器扩展存储中，不经过开发者服务器；
  > - 新标签页打开、课程识别规则、配置导入导出等小功能。
  >
  > 隐私：不收集统计、不做广告、不向开发者回传数据；详见隐私政策。
  > 说明：本扩展与 PTA 官方无关联；自动答题为实验性学习辅助，请遵守课程与学校规定。
- **截图**：至少 1 张 1280×800（Chrome/Edge 推荐；Firefox 也接受），截真实界面时去掉姓名、学号、成绩等个人信息。
- **图标**：已有 16/48/128；Chrome 建议再准备 440×280 小促销图（可选）。
- **审核备注**：PTA 需要登录才能看到核心界面，尽量提供一个可用的测试账号；不能提供时，附 1–2 分钟演示录屏和操作步骤。
- **权限说明**：见第 4 节，逐项复制到商店的 justification 字段。

## 3. 商店提交流程

### Chrome Web Store

1. 注册/登录 Chrome Web Store 开发者账号，完成身份与两步验证。
2. 「新增项目」上传 `...-chrome-...zip`。
3. 填写商品详情：名称、短描述、长描述、类别（生产力工具）、语言（中文）、图标、截图、支持 URL（GitHub Issues）、隐私政策 URL。
4. 「隐私权规范」页：
   - 单一用途：`帮助 PTA（pintia.cn）用户整理题目集、跟踪进度与截止时间，并可选用自己的 AI 服务辅助作答。`
   - 权限理由：逐项填写第 4 节。
   - 远程代码：选择「否，我没有使用远程代码」。
   - 数据使用：勾选 `网站内容`、`身份验证信息`、`个人身份信息`（邮件提醒可选），说明仅发送给用户自选服务、不经过开发者；勾选有限使用承诺。
5. 审核备注里写清：自动答题默认关闭；需要用户自备 API Key；不提供 Key 时审核员仍可验证列表增强、提醒与设置页。
6. 提交审核。被拒时先读拒绝理由，优先用 `STORE_SAFE` 思路裁剪功能而不是反复原样重提。

### Microsoft Edge Add-ons

1. 用 Microsoft Partner Center 创建开发者账号（免费）。
2. 新建 Edge 扩展项目，上传 `...-edge-...zip`（与 Chrome 同代码；Edge manifest 不写 Chrome 专属的 `minimum_chrome_version`）。
3. 填写商品详情、隐私政策 URL、支持 URL、截图。
4. 「Notes for certification」写清测试步骤、测试账号/录屏、自动答题默认关闭与 API Key 说明。
5. 提交认证。

### Firefox AMO

1. 注册 AMO 账号，开启两步验证（申请 API Key 需要）。
2. 「Submit a New Add-on」上传 `...-firefox-...zip`，选择 **listed**（商店可搜索）。
3. manifest 已包含：
   - `browser_specific_settings.gecko.id`（MV3 签名必需）
   - `strict_min_version: 140.0`
   - `data_collection_permissions.required: ["none"]`
   - `optional: ["websiteContent", "authenticationInfo", "personallyIdentifyingInfo"]`
4. 审核员若要求源码：提供 `src/` 与构建说明（`npm ci && npm run build -- --target firefox`）；本项目未压缩/混淆，通常可直接审阅 bundle。
5. 审核备注说明：
   - 自动答题默认关闭，开启时由弹窗请求可选数据收集同意；
   - 邮件提醒默认不生效（需用户填写自建后端），开启/填写时才请求 `personallyIdentifyingInfo` 与 `websiteContent`（payload 含邮箱与题目集标题/截止时间）；
   - 不连接开发者服务器，无统计与广告。
6. 提交。AMO 对数据声明与权限很严格，manifest 声明必须与代码行为一致。

## 4. 权限理由（可直接复制）

| 权限 | 理由 |
|---|---|
| `storage` | 保存扩展开关、课程识别规则、提醒配置、模型服务配置与用户自填的 API Key。 |
| `alarms` | 每隔一段时间扫描未关闭题目集，触发截止前 3 天/1 天的本地提醒。 |
| `notifications` | 在用户本机弹出题目集临近关闭的提醒；不产生网络请求。 |
| `host_permissions: https://images.ptausercontent.com/*` | 自动答题含图题时，由扩展后台带登录态读取题干/选项图片并转成 data URL 交给视觉模型；页面直接 fetch 被该域 CORS 拒绝。 |
| `host_permissions: https://opencode.ai/*` | 用户选择 OpenCode Go 作为模型服务时，由扩展后台把 chat/completions 请求转发到该网关；该域不返回 CORS 头，内容脚本直连必失败。只转发 `/inference/go/` 的 chat 端点，不做通用代理。 |
| `content_scripts: https://pintia.cn/*` | 在 PTA 题目集列表/答题页读取页面上的题目集与题目信息，渲染分组、筛选、进度、倒计时与悬浮答题面板。 |

数据披露口径：

| 数据类型 | 何时 | 去向 | 是否经过开发者 |
|---|---|---|---|
| 网站内容（题目文本/图片） | 用户开启自动答题并点击开始 | 用户选择的模型服务 | 否 |
| 身份验证信息（API Key） | 同上 | 同上，仅用于鉴权 | 否 |
| 个人身份信息（邮箱） | 用户配置并开启邮件提醒 | 用户自建邮件后端 | 否 |

## 5. 审核风险与应对

1. **登录墙导致审核员无法验证**：提供测试账号或录屏；弹窗、设置页与提醒配置无需登录即可查看。
2. **自动答题的学术诚信风险**：默认关闭、在说明中标注实验性与学习辅助用途；商店首图不突出“一键答题”；如被拒，改用只保留列表增强/提醒的商店版。
3. **数据外发**：隐私政策与商店问卷逐项一致；Firefox 用 optional + 运行时同意；不把数据发给开发者。
4. **主机权限过宽**：按第 4 节逐项解释；不要新增未使用的域。
5. **商标/仿冒**：名称与描述注明“非官方”，不使用 PTA 官方 logo；图标为自有图形。
6. **外部更新链接**：商店版由商店更新；Firefox 构建已在弹窗里隐藏 GitHub 更新入口（AMO 负责更新）。Chrome/Edge 的更新行只是信息性链接，若审核追问可改为指向商店条目。
7. **Firefox 数据声明不实**：manifest 的 optional 类别与 `requestDataConsent` 调用保持一致；新增外发功能时同步更新声明与隐私政策。

## 6. 上线后的更新

- 版本号只改 `src/manifest/base.json` 的 `version`，重新 `build --target all`，提交生成的 `extension/`，打 tag 后由 `release.yml` 产出 GitHub 包与三个商店包。
- 三个商店各自上传新 zip；Firefox AMO listed 版本只能通过 AMO 更新，不要设置 `update_url`。
- 现有 sideload 用户升级到商店版时扩展 ID 会变化，`chrome.storage` 不会自动迁移；先让用户用「配置导入导出」导出，再安装商店版导入。安装教程与 Release 说明要同步提示。
