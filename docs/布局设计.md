# 布局设计

## 设计原则

- **视觉对齐 PTA**：卡片白底圆角阴影、胶囊徽章、主色取 PTA 的交互蓝 `hsl(212,89%,53%)`（= #1C80F2，2026-10-16 实测；`#0a4991` 是它的品牌深蓝，只出现在输入框聚焦环里，别当选色用）；非当前页的重建卡片直接复用 PTA 编译后的样式类，观感与原生一致。
- **跟随页面主题**：暗色跟着 PTA 自己的 `.dark` 类（实测挂在 `<body>` 上）而不是系统设置——用户在 PTA 里选的浅色/暗色才作数（令牌见 `extension/content/styles.css` 顶部注记）。
- **不破坏原有能力**：PTA 自己的搜索/筛选/排序全部照常工作（其重渲染会触发插件重新同步）。
- **可关闭**：总开关关闭后页面与原版完全一致（移除全部注入元素）。

## 视图状态机（v0.5.1）

**所有列表页的「全部」默认 = 列表**（进入路由时恢复默认，会话内可用 toggle 切换分组，不持久化），两种视图都有分页；排序一律沿用 PTA 当前排序：

| 状态 | 显示 | 分页 |
|---|---|---|
| 全部（**默认 = 列表**） | PTA 原生列表，卡片带徽章/倒计时，筛选条悬浮其上 | PTA 原生分页 |
| 全部 + 分组（toggle 切换） | 聚合分组区段（可折叠、组头带最近关闭时间），PTA 分页条隐藏 | **整组分页**（页容量 30，组不跨页，自绘分页条「共 N 条数据」） |
| 选中具体课程（两页相同） | 该课程平铺列表（聚合全部页、无组头） | 无（单课程 ≤ 一页容量） |

├──────────────────────────────────────────────────────────────┤

├──────────────────────────────────────────────────────────────┤
│ ▾ ● 算法设计与分析  7 个             最近关闭 10-17 23:59      │ ← ② 分组头（可折叠）

│   └────────────────────────────────────────────────────────┘ │
│ ▸ ● 数据结构  23 个                  最近关闭 01-20 23:59      │
│   …（按整组分页：页容量 30、组不跨页，自绘「共 69 条数据」分页条）│

### 元素说明

- **① 课程筛选条**：胶囊 chip 显示「课程名 + 数量」（计数为**跨页聚合**的全量数量，翻页不变），点击即筛。**课程级开放状态**（v0.5.2）：还有未关闭题目集的课程，数量**蓝色高亮**（部分关闭时显示 `开放/总数`，如 `4/7`）；已全部关闭的课程**整颗灰显**；两者均有悬停提示。判定与卡片徽章一致——按题目集关闭时间（endAt），"未开放"计入未关闭（课还没上完，仍是活跃课程）。**两种模式常驻**且 `position: sticky` 吸顶悬浮（实测滚动 3000px+ 始终钉在内容区顶部）；右侧「切换为列表/切换为分组」toggle **仅在「全部」激活时渲染**（列表/分组切换只影响「全部」，见状态机）。
- **② 分组头**：课程色圆点（按课程名哈希着色）+ 课程名 + 数量，右侧显示该组**最近的关闭时间**（哪门课快截止一眼可见）；点击折叠/展开。分组顺序 = 聚合数据（即用户在 PTA 选的排序）中各组首次出现的位置，组内保持该排序，不做二次排序。
- **③ 课程徽章**：每张卡片副标题行行首的课程小胶囊，按课程名哈希着色。
- **④ 截止倒计时**：仅 ≤7 天显示（避免满屏"剩 82 天"），<24h 红色加粗、<48h 橙色，其余灰色；卡片自带 PTA 精确倒计时时不再叠加。悬停显示完整关闭时间。
- **⑤ 答题进度（v0.8）**：状态徽章行尾部的 `已完成`（绿）/`未完成`（橙）胶囊 + 副标题行尾部的 `已作答 7/15`，回答"这个题目集还剩没剩题"（口径见[《核心结论》§2.1](./核心结论.md)）。

### 卡片局部（新增元素位置）

```
┌────────────────────────────────────────────────────────────┐
│ 🖥  算法设计与分析--课堂练习2-1   [已开考][已开放][未完成]     │
│     [课程徽章] 关闭时间: 2026-10-18 23:59 已作答 7/15 [剩X天] │
└────────────────────────────────────────────────────────────┘
      ↑ ③                          ↑ ⑤           ↑ ④
```

### 答题进度（⑤）的取舍

- **只在拿得到进度时出现**：考试型（`examIdByProblemSetId` 命中）**且**已开始**且**未关闭的题目集才显示——非考试型没有进度接口（PTA 自己也不显示），未开始/已关闭的题目集不取数（理由与请求量见[《核心结论》§2.1](./核心结论.md)）。数据晚到时先渲染卡片、拿到后按签名重建，不整页闪。
- **胶囊尺寸对齐 PTA 原生**（`px-3 py-1`、12px、`rounded-xl`），颜色沿用页面既有的绿/橙语义（已完成≈已开考，未完成≈未开放）；**不做进度条**——PTA 概览页的进度条是原生 React 组件，卡片上只有一行位置，胶囊 + 分数更省空间，也不与 PTA 的渲染抢 DOM。

### 跨页聚合的呈现方式

分组视图展示**全部页**的题目集：

- 当前页的条目**克隆 PTA 原生卡片**（保留全部类名、状态徽章与悬停效果）；
- 其他页的条目按接口数据**重建卡片**（复用 PTA 的样式类，观感一致；状态徽章由时间推导）；
- PTA 自身的分页条/条数文案在分组视图下**隐藏**（它只作用于被隐藏的原列表，留着会误导），切回列表模式时恢复。

## 平铺列表（选中具体课程）

与分组视图同一套聚合数据，仅呈现方式不同：

- 无分组头，该课程全部题目集按 PTA 当前排序一页铺开（跨页聚合，如"数据结构"23 条一次看全）；
- 卡片仍为「当前页克隆 + 其他页接口重建」，课程徽章与倒计时照常；
- PTA 分页条隐藏（单课程条数有限，无需分页）；toggle 隐藏，点「全部」回到切换前的分组/列表状态。
