# 隐私政策

生效日期：2026-11-20

适用扩展：**更好的题目集（PTA 增强）**（以下简称“本扩展”）。

本扩展是非官方工具，与 PTA（pintia.cn）及其运营方无隶属或合作关系。本政策说明本扩展读取哪些数据、数据何时离开本机、以及用户可以如何控制。

## 1. 一句话概括

本扩展**不运营开发者服务器，不做统计、广告或用户画像，不向开发者回传任何数据**。页面内容只在用户主动开启自动答题时，由用户自己的浏览器发往用户自己选择的模型服务；邮件提醒只发往用户自己填写的自建服务端。

## 2. 本扩展读取哪些数据

- **PTA 页面内容**：题目集列表、课程/教师/单位、开放与截止时间、答题状态、题目正文与图片。用于列表分组与筛选、进度胶囊、截止倒计时、提醒判定；开启自动答题时还用于生成模型请求。
- **扩展设置**：开关、课程识别规则、提醒配置、模型服务/模型名/端点等。存放在浏览器扩展存储中。
- **API Key**：用户为自动答题自行填写的模型服务密钥。仅存放在浏览器扩展存储中，用于向用户选择的模型服务发起请求。
- **邮箱地址与自建服务器地址**（可选）：仅在用户开启邮件提醒并填写后使用。

## 3. 数据何时离开本机

1. **自动答题（默认关闭，需用户主动开启）**
   - 开启后，题目文本、题干/选项图片会随模型请求发送到用户选择的模型服务：DeepSeek 官方端点、OpenCode Go 网关，或用户自填的任意 OpenAI 兼容端点。
   - 该服务的 API Key 只随请求发送给该服务，用于鉴权。
   - 请求由用户当前浏览器发起（OpenCode Go 经扩展后台转发），**不经过开发者服务器**。
   - 第三方服务如何存储和处理请求，取决于该服务自己的隐私政策；请在使用前阅读并自行评估。
2. **邮件提醒（可选，需用户自建后端）**
   - 开启后，邮箱地址与未关闭题目集的元数据（标题、截止时间、教师、单位等）会发送到用户填写的自建后端，由该后端发送提醒邮件。
   - 该后端由用户自行部署和运营，**不是开发者提供的服务**。
3. **检查更新（信息性）**
   - 扩展会向 GitHub 的公开 API 请求本仓库最新 Release 的版本号与链接，不携带用户身份或页面内容。
4. **浏览器通知（纯本地）**
   - 提醒在用户本机由浏览器通知系统弹出，不产生网络请求。

## 4. 开发者不收集什么

开发者**不收集、不存储、不出售、不共享**以下数据：页面内容、API Key、邮箱、答题记录、浏览历史、设备标识、使用统计或崩溃日志。本扩展不包含分析 SDK、广告 SDK 或远程代码。

## 5. 存储与保留

- 设置存放在浏览器的扩展存储中（`storage.sync` / `storage.local`）。使用 `storage.sync` 时，数据可能随用户的浏览器账号在设备间同步；同步由浏览器厂商提供，开发者无法访问。
- API Key 与提醒邮箱目前也存放在扩展设置中，因此可能随浏览器账号同步。用户可在扩展的「配置导入导出」中导出或导入设置；**导出的 JSON 包含 API Key，请妥善保管**。
- 卸载扩展会删除扩展存储；已同步到浏览器账号的数据可在浏览器账号的同步设置中清除。

## 6. 第三方服务

用户可能通过本扩展连接以下第三方，具体数据处理以对方的隐私政策为准：

- DeepSeek：<https://www.deepseek.com/>
- OpenCode Go / opencode.ai：<https://opencode.ai/>
- 用户自填的 OpenAI 兼容模型端点
- 用户自建的邮件提醒后端
- GitHub（检查更新）：<https://github.com/>

## 7. 用户的选择与控制

- 自动答题与邮件提醒默认不会发送任何数据；自动答题总开关默认关闭。
- 关闭自动答题、关闭邮件提醒、清空模型 Key 或服务器/邮箱后，对应数据不再外发。
- Firefox 用户可在 `about:addons` 的「权限和数据」中查看并撤销站点权限与可选数据收集同意；本扩展在功能开启时会请求对应同意。
- 用户可随时卸载扩展以停止全部功能。

## 8. 安全

- 模型与更新请求使用 HTTPS；OpenCode Go 的跨源请求由扩展后台转发并限定到其 `/inference/go/` 端点。
- 自建邮件后端若使用 `http://` 明文地址，传输内容可能被网络中继读取；建议用户为自己的后端启用 HTTPS。
- API Key 只应填写在可信设备上；导出配置时请避免把文件发给他人。

## 9. 学习用途与学术诚信

自动答题是实验性的学习辅助功能，输出可能出错。请遵守课程、学校和平台的规定；是否使用、如何使用由用户自行决定并承担相应后果。
