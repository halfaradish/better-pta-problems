# 自动答题（实验，v0.9）

用你自己的 LLM 账号，在题目列表页自动作答判断题 / 单选题 / 填空题（多空支持）与**编程题**（跨页逐题串行，每题真实提交一次）。实验功能默认关闭，随「开始答题」按钮显式触发，平时不产生任何请求。

## 使用步骤

1. 插件弹窗 → 打开「自动答题面板」开关（实验功能默认关）；
2. 打开题目列表的任意题型页，右下角出现悬浮答题球，点开悬浮面板。面板分**「答题配置 / 模型配置」**两页：

   - 答题配置 = 语言（编程题）、覆盖已作答、作答含图题、开始/中止答题与运行日志；
   - 模型配置 = 服务 / 端点 / 模型 / API Key。在「服务」里选择适配的模型——已适配 DeepSeek 官方 API（deepseek-flash 视觉）与 OpenCode Go 网关（官方基址 `https://opencode.ai/inference/go/openai/v1`，默认模型 glm-5.3-flash 且可自填，仅 chat 系模型可用），也可选「自定义」填写任意 OpenAI 兼容端点 + 模型 id。OpenCode Go 只支持走 `/chat/completions` 的模型系（GLM / Kimi / DeepSeek / LongCat / MiMo 等）；Claude、GPT/Grok、Gemini 等走别的协议，填了会在开跑前直接报错，不会白耗请求。

   **每个服务各存一份 API Key**（仅存本机浏览器，切换服务自动带出各自的 Key，互不覆盖；输入框用文本遮罩而非密码框，浏览器的密码管理器不会再误弹「要更新密码吗？」）。按需打开「覆盖已作答」；编程题多一行「语言（编程题）」——可跟随编辑器当前语言（默认）或固定为某一种（选项即本题集允许的语言白名单）。悬浮球可按住拖到页面任意位置（位置本机记住，球在任何角落面板都会自动朝空余一侧展开）；
3. 点「开始答题」：插件自动遍历该题集的全部题型页（判断 → 单选 → 填空 → 编程），客观题逐题把题干连同选项交给模型，把返回的字母 / TRUE / FALSE / 填空数组写入表单，每个题型页答完点一次 PTA 原生「保存」；**编程题**则转入逐题串行续跑：每题单独加载一个文档，把题面交给模型出码、写入该题草稿并种入本地水合键让编辑器回带代码（校验语言与代码一致后才提交），逐题点「提交本题作答」真实评测。
4. 已作答的题默认跳过（「覆盖已作答」开关重答全部）。**客观题**里题干/选项含图的题默认跳过并在日志报告——你用的是视觉模型时，可以打开「作答含图题」：插件会同你的登录态下载图片、编码后交给模型作答。**编程题没有视觉链路**：含图的编程题照常按文字题面作答并真实提交，日志会写明「编程题暂不支持图片输入」；「作答含图题」开关只作用于客观题。

## 运行中的中止与日志

- **运行中同一个按钮变为「中止答题」**，随时可叫停（含编程题续跑的任意一页）：在途请求立即断开、未开始的题目与题型不再作答、已填答案所在页照常保存（防「已填未存」被当作已答跳过）。
- 进度显示在悬浮球的进度环与面板日志里；日志可清空，每题请求前后实时记录（每题请求前记「请求模型中…」）、失败当场报告，编程题跨页作答时日志随各页出现、结束汇总带逐题失败明细。
- **日志跨页保留**：编程题续跑每页都要整页装载，日志会写进当前标签页的 `sessionStorage`，新页面挂载时先回放整轮历史（上限 200 行）；「清空」会同时清掉持久化的日志。此前失败清单只在历史日志丢失时兜底回放。
- LLM 请求设 120 秒上限（服务挂起不再吊住整个流程，超时报「已按超时中断」）。429 / 5xx / 网络错误最多重试 3 次（指数退避 + 抖动）；400 / 401 / 403 这类配置或凭证错误不重试，直接报告网关返回的错误类型与消息。
- **运行期会临时压住 PTA 的离开确认**（切换题型的 `confirm` 与整页卸载的 `beforeunload` 原生框），避免续跑翻页被「离开此网站？」打断；运行结束恢复。万一页面被其他原因拦下、10 秒内没有跳转，插件会自动重试一次，仍失败则明确报错并停止本轮（不是静默停在待机）。

## PTA 访问频率限制

编程题续跑每题需要整页装载两次（写草稿一次、水合校验一次），连续翻页可能触发 PTA 的「您访问得太快啦，不如休息一会儿吧」错误页。插件现在：

- 每次切题/重载前等待 **1–5 秒**（随机抖动，日志会写明「等待 Ns 再切换」），只求错开连续整页装载，不再拖慢整体节奏；
- 一旦在页面上识别到限流错误，暂停并回到续跑单里当前题的 URL 重试，冷却依次为 **60s → 120s → 180s**；三次仍被拒绝才停止（已完成的题目保持各自状态，不会重做）；
- 限流页不会被当成「收不到题目」继续翻页，也不会因为错误页换了地址而误判成你手动导航。

如果你手动操作时遇到这个错误：等几分钟再进入题目即可，不要连续快速点击下一题；正在续跑时也不要手动切换题目，否则续跑会按「页面已离开本题」取消。

## 说明与限制

- DeepSeek 与「自定义」服务由页面上下文直连（端点需允许跨域）；**OpenCode Go 因网关不返回 CORS 头，改由扩展后台转发**，同样不经过第三方服务器，请求只发往 opencode.ai。模型回答质量由所选模型决定，作答是否正确需自行核对（答题中的题集 PTA 不提供对错反馈）。
- **纯文本模型看不见图片**——客观题含图题要么跳过，要么切到视觉模型并开启「作答含图题」；编程题不接图片输入，含图题按文字题面作答并在日志注明。OpenCode Go 各模型的图像输入能力官方未逐项标注，选用前请自行验证。
- **OpenCode Go 的用途边界**：官方文档说明该套餐面向 OpenCode 与其他 coding agent 类流量，并会监控滥用行为。用订阅额度作答客观题可能超出其预期用途，请自行评估；编程题相对接近其目标场景。
- **编程题提交即评测**：自动作答会实时生成提交记录与作答度，成绩由评测结果（代码正确性与运行时限）决定，与客观题的静默判分路径不同（面板底部有同样的固定说明）。
