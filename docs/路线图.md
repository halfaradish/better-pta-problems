| v0.6.1 | 后端提醒合并发送：同一轮检查中同邮箱同档位到期的多条提醒合并为一封汇总邮件（多门课同一时间截止时不再连环发信；错峰截止各自触发、宕机积压也并成一封），单条场景主题格式不变 |
| v0.6.2 | 弹窗「启用邮件提醒」独立开关（关闭即暂停上报，保留服务器/邮箱配置；重新打开立即补一次同步，服务器/邮箱输入随开关禁用）；「发送测试邮件」防连点：插件侧 60s 冷却计时（storage.session 持久化，重开弹窗不绕过）+ 后端 `/api/test` 每邮箱冷却（`TEST_COOLDOWN_SECONDS`，默认 60s，超频 429）双保险 |
