# 更好的题目集 · 安装教程

「更好的题目集」是一个浏览器扩展（支持 Chrome / Edge），在 PTA（pintia.cn）的「活跃题目集」「所有题目集」列表页按课程分组与筛选，并在卡片上显示课程、截止倒计时和答题进度。压缩包里的 `extension` 文件夹就是扩展本体，本教程教你把它装进浏览器。

装好之后你会得到：课程筛选条与课程分组、卡片上的课程标签与倒计时、答题状态（已完成 / 未完成 / 未答题）。自动答题、邮件提醒是两个可选功能，默认关闭、需要自己额外配置，见文末说明。

## 一、安装（三步）

### 1. 解压到一个固定的位置

把压缩包解压出来的文件夹放到一个**以后不会移动、不会删除**的位置，例如 `D:\better-pta-problems\`（别放在「下载」里随手清理）。

解压后的目录结构（`vX.Y.Z` 是版本号）：

```
better-pta-problems-vX.Y.Z/
├── extension/        ← 第 3 步要选的就是这个文件夹
└── 安装教程.html
```

「固定位置」很重要：浏览器记住的是这个文件夹的路径，路径一变（挪动、改名、删除）扩展就会失效。以后升级新版本，只要把新的 `extension` 覆盖到同一位置即可。

### 2. 打开扩展管理页，开启「开发者模式」

在浏览器地址栏复制粘贴下面这行，回车打开：

- Chrome：`chrome://extensions`
- Edge：`edge://extensions`（Edge 的用词不同：开关叫「开发人员模式」，在页面左下方；按钮叫「加载解压缩的扩展」）

打开页面上的「开发者模式」开关（Chrome 在右上角）。

### 3. 「加载已解压的扩展程序」，选择 `extension` 文件夹

点上方的「加载已解压的扩展程序」按钮 → 在弹出的选择框中进入刚才解压的位置 → **选中 `extension` 文件夹**（里面装着 `manifest.json` 的那一层，不是外面那层）→ 点「选择文件夹」。

页面上出现「更好的题目集（PTA 增强）」卡片，就是装好了。

> **如果报错「清单文件缺失或不可读」**：说明选错了文件夹（选成外层了）。重新点一次按钮，进到 `extension` 里面再选。

## 二、确认装好了

1. （可选）点浏览器工具栏的扩展图标（Chrome 是拼图形状），把「更好的题目集」旁边的图钉点亮——它会常驻工具栏，之后点图标就能打开设置弹窗。
2. 打开 PTA 题目集列表页（[pintia.cn](https://pintia.cn) → 进入某个课程 → 活跃题目集 / 所有题目集）。页面出现课程筛选条、卡片上多出课程标签与状态胶囊，即一切正常。
3. **已经打开着的 PTA 页面要刷新一次**才会生效。

## 三、升级到新版本

1. 下载新版本的压缩包并解压，找到里面的 `extension` 文件夹；
2. 用它**覆盖第 1 步那个固定位置里的 `extension`**（保持路径不变，把旧文件夹整个替换掉）；
3. 回到 `chrome://extensions`，在「更好的题目集」卡片上点刷新图标（↻）；
4. 回到 PTA 页面刷新一次。

只要覆盖到同一位置，就不用卸载重装，设置（含自动答题的 API Key、邮件提醒配置）都会保留。

**如果你装的是旧结构版本**（解压出来直接是 `manifest.json`、没有外层文件夹，v0.9.6 及以前的压缩包）：新旧结构的目录不同，浏览器视为两个不同的扩展，无法直接覆盖，需要按下面的步骤迁移：

1. 打开旧版的设置弹窗 → 点页脚的「导出配置」，保存 JSON 文件；
2. 到 `chrome://extensions` 把旧的「更好的题目集」卡片**移除**（移除会清空该扩展的全部设置，所以第 1 步必须先做）；
3. 按本教程第一、二节重新安装新版本；
4. 打开新版的设置弹窗 → 点页脚的「导入配置」，选择刚才导出的 JSON。

## 四、常见问题

**装好后 PTA 页面没变化？**

- 刷新已打开的 PTA 页面（扩展在页面加载时注入）；
- 确认是在「活跃题目集 / 所有题目集」这类列表页——题目集详情页、首页不会有筛选条；
- 到 `chrome://extensions` 确认「更好的题目集」处于启用状态。

**想临时关掉？** 到 `chrome://extensions` 把它的开关关掉即可，设置不会丢。

**自动答题不可用？** 它默认关闭，且需要自备一个大模型服务的 API Key（支持 DeepSeek 官方、OpenCode Go 网关等 OpenAI 兼容接口），在设置弹窗的「自动答题」里选好服务、填上 Key 才能开始。API Key 只存在你自己的浏览器里。

**收不到邮件提醒？** 邮件提醒需要你自己部署一个轻量后端（仓库的 `server/` 目录）并在弹窗里填写服务器地址与邮箱，属于进阶功能；不部署不影响其他功能。

其他问题、功能建议可以到仓库提 Issue：<https://github.com/halfaradish/better-pta-problems>
