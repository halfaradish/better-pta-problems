# 课程识别策略

PTA 的接口数据里没有课程归属字段，课程信息只存在于标题命名约定中。识别按以下优先级**逐层回退**，并在最后做**同教师相似归并**消除碎片组。

| 优先级 | 来源 | 说明 | 示例 |
|---|---|---|---|
| 1 | 自定义规则 | 弹窗中配置，每行 `关键词=>课程名`（包含匹配，**优先于一切自动识别**） | `2025-=>2025级Java` |
| 2 | 分隔符 | 取首个分隔符前段（弹窗可配，默认 `--` `｜` `\|`；多个分隔符命中时取位置最靠前的） | `算法设计与分析--课堂练习1-3` → **算法设计与分析** |
| 3 | 类型关键词 | 作业/实验/考试/期中/期末/测试/复习题/随堂/上机/课堂练习/测验/项目/Lab/HW… 从左到右找到**首个能构成有效课程名**的命中 | `数据结构复习题(树一)` → **数据结构**；`2024程序设计基础-作业8` → **2024程序设计基础** |
| 4 | 学年前缀兜底 | 标题以 `YYYY-` 开头（`—`、`·` 同理）且以上全部未命中时，用年份作课程名 | `2025-实验3` → **2025** |
| 5 | 同教师相似归并 | 同一教师名下，自动识别出的课程名做**最长公共子串**匹配归并（见下） | 同教师的 `2025`+`2025-期中` → **2025** |
| 6 | 未分类 | 以上全部失败 | 归入「未分类」组 |

## 课程名整理

- **尾部清理**：关键词/分隔符截出的课程名会去掉尾部残留的分隔符（`数据结构-` → `数据结构`、`2024程序设计基础-` → `2024程序设计基础`）。
- **纯数字拒绝**：关键词层产生的纯数字段（如年份 "2025"）不作为课程名，继续尝试下一命中——避免 "2025-期中考试" 被归成无意义的 "2025"（该例最终经关键词命中 "期中" 得到 "2025-期中"）。
- 关键词命中位置需在标题第 3 个字符之后且前段含非数字，避免 `作业1` 这类标题误判。

## 同教师相似归并（优先级 5 的算法）

用户提案：**先按教师粗分类，再匹配最长公共子串做二次归并**。实现：

1. **教师分区**：以题目集创建者（接口 `ownerNickname`）为命名空间，归并只发生在同一教师名下，不同教师的相似课名互不污染。
2. **相似判定**：两课程名的最长公共子串长度 ≥ `max(4, 短名长度 × 60%)` 即视为同一门课。
   - 归并：`2025`~`2025-期中`（LCS=4）、`2024程序设计基础`~`-242`（LCS=11）
   - 不归并：`2024`~`2025`（LCS=3）、`操作系统`~`操作实训`（LCS=2）
3. **传递闭包**：用并查集聚类（A~B、B~C 则 A~C 一组）。
4. **组名选取**：取簇内**条目数最多**的名字（并列取最短的基础名）——保证大头组的语义不被个别变体带偏。
5. **显式意图保护**：自定义规则命中的课程名（locked）不参与归并、也不会被归并改名。

## 真实数据验证（69 条，归并后）

| 课程组 | 条数 |
|---|---|
| 算法设计与分析 | 7 |
| 代数结构与初等数论 | 11 |
| 数据结构 | 23 |
| 2024程序设计基础 | 13 |
| 2025 | 15 |

零未分类、零碎片组。其中"数据结构"组覆盖了 复习题×5、作业、实验三~八、期中测试 等多种命名变体；"2025"组由学年前缀兜底 + 归并产生（Java 课程，教师D，含期中考试）。若希望某组换名字（如"2025"→"2025级Java"），加一条自定义规则即可。

## 配置入口

工具栏弹窗：四个开关（启用/分组视图/徽章/倒计时）+ 归并开关（"同教师相似课程名归并"）+ 分隔符配置 + 自定义规则文本框。所有配置存 `chrome.storage.sync`，跨设备同步，改动即时生效（页面会自动重建视图）。
