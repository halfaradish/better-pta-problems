# 题目关闭邮件提醒（可选）

页面内的倒计时只是展示；想在题目集截止前收到**邮件**提醒，需要自建一个轻量后端（仓库里的 [`server/`](../server/README.md)）。这是可选功能，默认关闭，不配置就完全不外发任何数据。

## 使用步骤

1. 部署后端：见 [server/README.md](../server/README.md)（systemd / Docker 现成配置，QQ/163 邮箱 SMTP 授权码教程在内；要求 Node ≥ 22.5，数据库用内置 `node:sqlite`，无需安装数据库）；
2. 插件弹窗 → 「题目关闭倒计时提醒」分类 → 打开「启用邮件提醒」→ 填服务器地址（`ip:port`，后端配置了令牌则写 `ip:port/令牌`）与目标邮箱 → 点「发送测试邮件」验证（60 秒冷却，防连点）；
3. 之后每次打开 PTA（任意页面，含 dashboard 与题目集详情页），未关闭题目集会自动同步到后端，截止前默认提前 3 天、1 天各收到一封邮件（具体档位由后端 `REMIND_BEFORE_MINUTES` 配置）；同一时间到期的多个题目集会合并成一封汇总邮件，不会连环轰炸。

## 提醒范围与开关

- **只同步题目集的 id / 标题 / 教师 / 单位 / 截止时间**，不含任何答题与学习行为数据；清空弹窗里的服务器地址或邮箱即完全关闭该功能。
- **已完成的不再提醒**（v0.9.4 起的独立开关，默认开）：已答完的题目集不再占用提醒邮件。判定与卡片上的答题状态胶囊共用同一口径（v0.9.6 起为「有提交就算」，见[《核心结论》§2.1](./核心结论.md)）；进度取不到或非考试型题目集一律按未完成保留，宁可多提醒、不漏提醒。
- 非考试型题目集 PTA 不提供进度接口，无法判断是否做完，因此始终照常提醒。

同步时机（打开页面约 2 秒后推送一次、进行中页聚合刷新、配置变更即时推送）与节流规则、后端扫描与合并逻辑、安全边界等实现细节，见[《核心结论》§6.1](./核心结论.md)。
