# 更好的题目集（Better PTA Problem Sets）

一个针对 [PTA（pintia.cn）](https://pintia.cn) 的浏览器扩展：在「活跃题目集」「所有题目集」列表页**按课程分组与筛选**，并给卡片加上课程徽章与截止倒计时，解决不同课程题目集混在一起、难以浏览的问题。

主要能力：

- **课程分组 / 筛选与跨页聚合**——复用 PTA 自己的列表接口，筛选条常驻吸顶并区分课程开放状态；
- **答题状态与进度**——卡片显示 `已完成` / `未完成` / `未答题` 胶囊与 `已作答 N/M`，口径为「有提交就算」；
- **题目关闭邮件提醒**（可选，v0.6）——配自建轻量后端，截止前 3 天 / 1 天各发一封邮件；
- **自动答题**（实验，v0.9，默认关）——用你自己的 LLM 账号作答判断 / 单选 / 填空 / 编程题；
- 另有「新标签页打开题目集」（默认开）等小开关。

当前版本 **v0.9.6**：修复「题目集全部答完仍显示未完成 0/N」，答题进度与提醒统一为「有提交就算」。逐版本历史见[《路线图》](./docs/路线图.md)，文档索引见文末。

## 安装与更新

**普通用户**：到 [Releases](https://github.com/halfaradish/better-pta-problems/releases) 下载最新的 `better-pta-problems-v*.zip`，解压到一个固定位置，双击里面的 `安装教程.html` 跟着做即可。压缩包解压后是一个目录，里面是扩展本体 `extension/` 与《安装教程》——在 `chrome://extensions`（Edge 为 `edge://extensions`）打开开发者模式，点「加载已解压的扩展程序」，**选解压目录里的 `extension` 子文件夹**。升级时把新包里的 `extension` 覆盖到同一位置、回扩展页在卡片上点「刷新」（↻），设置不会丢。完整说明见[《安装教程》](./docs/安装教程.md)（同一份正文打包时渲染成压缩包里的 `安装教程.html`）。

**从仓库源码**（开发者）：`chrome://extensions` → 开发者模式 →「加载已解压的扩展程序」→ 选仓库里的 `extension/` 目录（构建产物已随仓库提交，克隆后无需先构建）。

本地预览：浏览器直接打开 `preview.html`（mock 了数据与接口，实际运行 `core.js`，可验证聚合/筛选/折叠/模式切换）。

## 开发

源码在 `src/`，用 [esbuild](https://esbuild.github.io/) 打包成单文件写回 `extension/` 的**原有路径**——`manifest.json`、`preview.html` 与发版流程因此都不用改，产物也提交进仓库，克隆后可直接加载。

```bash
npm install
npm run build     # 一次性构建（改完 src/ 必须跑一次）
npm run dev       # 监听源码变化自动重建
npm run package   # 组装发行 zip（extension/ + 安装教程）到 dist/
npm test          # node:test 单测：识别/归并/整组分页/时间文案/设置迁移/数据源记账/答题进度口径/发行包
```

- 改代码改 `src/` 下的文件；`extension/` 里的 `content/core.js`、`background.js`、`popup/popup.js` 是产物（首行有「构建产物」标记），不要直接编辑。
- 发行包由 [tools/package.mjs](./tools/package.mjs) 组装：`extension/` + 由 `docs/安装教程.md` 渲染出的 `安装教程.html`（教程正文只维护 Markdown 一份，打包时渲染；zip 由 [tools/zip.mjs](./tools/zip.mjs) 写，显式带 UTF-8 文件名标志位）。
- CI（[check.yml](./.github/workflows/check.yml)）在每次推送/PR 跑单测、校验产物与源码一致、并给发行包做一次打包冒烟，出问题会直接失败。
- 发版（维护者）见[《发版流程》](./docs/发版流程.md)。

## 已知限制

- **PTA 改版**：接口路径、`.pc-list`、分页条类名（`paginationWrapper_*`）等若变化，表现为聚合退化为当前页分组或静默不注入，页面本身不受影响；控制台有警告。
- **聚合请求按路由记录**：PTA 标签切换是 SPA（同一文档），扩展把页面发出的列表请求按路径分别记录（v0.3.1 修复：此前取"全局最新请求"，快速切换标签"所有→活跃→没加载完就切回"会把活跃页的请求错当所有页的数据源，导致串页）。换页时筛选状态自动重置为全部。
- **聚合失败自动恢复**（v0.5.3）：切换路由会中止在途的旧聚合请求（不产生报错）；请求失败（网络抖动等）30 秒后自动重试，期间暂用上次聚合结果，从未成功过才退回当前页数据——插件视图可能短暂变少，页面本身不受影响。
- **排序语义**：组序 = 聚合数据（即用户在 PTA 选的排序）中各组首次出现的位置；组内保持该排序。
- **"已开考"徽章启发式**：关联考试 + 已开始 + （开放中或 7 天内关闭）时显示；极老考试集与 PTA 展示可能有细微出入。卡片自带 PTA 精确倒计时（"距离关闭还有…"）时不再叠加插件的倒计时。
- **答题进度的适用范围**（v0.8）：只对**考试型**（PTA 返回了 `examIdByProblemSetId` 关联）且**已开始、未关闭**的题目集显示——非考试型题目集 PTA 不提供进度接口（它自己的概览页也只显示"未答题/答题中"），已关闭的题目集不再取数（补做不了，也避免为几十个历史题目集逐个打接口）。进度按 2 分钟缓存，刚答完题切回列表页可能最多滞后 2 分钟。
- **暗色模式**：注入 UI 按浅色绘制（PTA 的暗色变量未适配）。
- **邮件提醒的同步时机**：打开 PTA 任意页面约 2 秒后自动推送一次；「进行中」页的聚合刷新可在会话中途捕获教师改期；配置变更即时推送。仅随「启用邮件提醒」开关生效（v0.7.1 起不再依赖「启用增强」，关掉页面增强也能收提醒）。
