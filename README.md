# 更好的题目集（Better PTA Problem Sets）

一个针对 [PTA（pintia.cn）](https://pintia.cn) 的浏览器扩展：在「活跃题目集」「所有题目集」列表页**按课程分组与筛选**，并给卡片加上课程徽章与截止倒计时，解决不同课程题目集混在一起、难以浏览的问题。

当前版本 **v0.5.3**：所有题目集列表页默认 = PTA 原生列表（分页可用）+ 悬浮课程筛选条；筛选条区分课程开放状态——还有未关闭题目集的课程计数高亮（部分关闭显示 `开放/总数`），已全部关闭的课程灰显。分组视图（聚合 + 整组分页器，组不跨页）与课程筛选（聚合平铺）经筛选条切换，toggle 只影响「全部」。含跨页聚合、同教师课程归并，均在真实登录环境（69 条题目集）端到端验证。

## 安装与更新

1. `chrome://extensions`（Edge 为 `edge://extensions`）→ 开发者模式 →「加载已解压的扩展程序」→ 选 `extension/` 目录。
2. **已装过旧版本**：在扩展卡片上点「刷新」（↻）后，重新打开题目集列表页。
3. 本地预览：浏览器直接打开 `preview.html`（mock 了数据与接口，实际运行 `core.js`，可验证聚合/筛选/折叠/模式切换）。

## 已知限制

- **PTA 改版**：接口路径、`.pc-list`、分页条类名（`paginationWrapper_*`）等若变化，表现为聚合退化为当前页分组或静默不注入，页面本身不受影响；控制台有警告。
- **聚合请求按路由记录**：PTA 标签切换是 SPA（同一文档），扩展把页面发出的列表请求按路径分别记录（v0.3.1 修复：此前取"全局最新请求"，快速切换标签"所有→活跃→没加载完就切回"会把活跃页的请求错当所有页的数据源，导致串页）。换页时筛选状态自动重置为全部。
- **聚合失败自动恢复**（v0.5.3）：切换路由会中止在途的旧聚合请求（不产生报错）；请求失败（网络抖动等）30 秒后自动重试，期间暂用上次聚合结果，从未成功过才退回当前页数据——插件视图可能短暂变少，页面本身不受影响。
- **排序语义**：组序 = 聚合数据（即用户在 PTA 选的排序）中各组首次出现的位置；组内保持该排序。
- **"已开考"徽章启发式**：关联考试 + 已开始 + （开放中或 7 天内关闭）时显示；极老考试集与 PTA 展示可能有细微出入。卡片自带 PTA 精确倒计时（"距离关闭还有…"）时不再叠加插件的倒计时。
- **暗色模式**：注入 UI 按浅色绘制（PTA 的暗色变量未适配）。
